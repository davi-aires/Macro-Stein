# 1.0.0 — adaptação para SVG 7.0

- Integração de entrada com as filas do launcher novo.
- Renderização das fontes, editor e overlay com Stein GFX.
- Restauração do estado gráfico e inversão de cores do cursor/ícone.
- Correção do setter de reflexão para recuperar as opções e o botão Macro Settings em Controles.
- Fontes da adaptação separados do pacote original, com build configurável e dependências fixadas por SHA256.
- Testes de entrada, verificação GFX do Loader e teste isolado das telas.

- Publicação com pacote completo, índice `steinmods.json` e checksums para atualização pelo Stein Client.
- Manifest de distribuição: versão da adaptação 1.0.0, modId `macros`, Loader mínimo 0.1.27 e créditos originais preservados.
